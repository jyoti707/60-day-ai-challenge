# 🧩 Prompt Puzzle — Master AI Prompting Through Play

**Day 35 of the #60DayClaudeChallenge**

Prompt Puzzle is an interactive, offline-first game designed to help users **learn prompt engineering through practice and play**.

Instead of simply reading about good prompts, players solve realistic prompting challenges, identify useful instructions, remove distracting ones, and compare weak prompts with optimized prompts.

## 🎯 What is Prompt Puzzle?

Prompt Puzzle turns prompt engineering into a gamified learning experience.

Players complete randomized scenarios across different prompting tasks and receive a **Prompt Performance Report** at the end of the session.

The current implementation focuses on **Software Development** scenarios such as:

* Code refactoring
* Unit testing
* API debugging
* API documentation
* SQL optimization
* Code review

Each scenario teaches a practical prompting principle such as:

* Defining a clear role
* Adding explicit constraints
* Specifying output format
* Providing relevant context
* Avoiding unnecessary scope
* Balancing clarity with efficiency

## 🎮 Challenge Types

The game contains exactly three challenge formats:

### 1. Build the Prompt

Drag the correct prompt blocks into the prompt area while avoiding distractors.

### 2. Clean the Prompt

Identify and remove unnecessary or harmful instructions from a cluttered prompt.

### 3. Choose the Best Prompt

Compare a weak, optimized, and over-engineered prompt and select the one most likely to produce the desired output.

## 🧠 Prompt Engineering Concept Learned

### Specificity & Constraints

One of the biggest lessons from Prompt Puzzle was that **a vague instruction leaves too much room for the AI to guess**.

For example:

> "fix this code"

is much weaker than:

> "Act as a senior JavaScript engineer. Refactor the following function for readability and maintainability without changing its behavior. Keep the function signature identical and explain each change."

The optimized version provides:

**Role + Task + Constraints + Expected Output**

This makes the AI's response more predictable, relevant, and easier to evaluate.
