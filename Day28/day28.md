# Day 28 – Hospital Admission Readiness Simulator

## Challenge
Built a Hospital Admission Readiness Simulator using Claude AI.

## Objective
Create an interactive simulator that allows users to act as a Hospital Admission Coordinator and determine whether a patient is ready for admission based on administrative and clinical readiness.

## Technologies Used
- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Claude AI

## Features
- Hospital admission setup form
- Provider and physician information
- Multiple diagnosis options
- Multiple admission types
- Prior Authorization workflow
- Admission readiness score
- Insurance verification
- Bed assignment tracking
- Documentation validation
- Physician orders verification
- Consent management
- Workflow timeline
- Care coordination cards
- Risk tracking dashboard
- Governance Snapshot
- Final Admit / Not Ready decision
- Restart simulation

## Key Learning

One important operational insight I learned is that hospital admission is not based only on the patient's medical condition. Administrative readiness—including Prior Authorization, insurance verification, physician documentation, bed availability, and patient consent—is equally important. A delay in any one of these processes can postpone admission even when clinical care is ready.
