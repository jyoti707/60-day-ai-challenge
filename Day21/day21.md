# 🔐 Digital Privacy Intelligence Dashboard

An interactive cybersecurity-inspired dashboard built using HTML, CSS, and JavaScript that visualizes a user's digital footprint and privacy exposure from a self-reported dataset.

## 🚀 Features

* 📊 Digital Footprint Score
* 🔒 Privacy Score
* 🌡️ Exposure Heatmap
* 🏢 Company Exposure Ranking
* 📋 Data Collection Matrix
* 🎯 Risk Radar
* 👤 Digital Twin Profile
* 💎 Most Valuable Data Assets
* 💡 WOW Insights
* 🎛️ Interactive Privacy Improvement Simulator
* ✅ Final Privacy Verdict

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* SVG Animations
* Responsive Design

## ✨ Key Learning

Building this dashboard helped me understand how a few commonly used apps can collectively create a much larger digital footprint than expected. It also reinforced the importance of separating **facts** from **estimates** while presenting privacy-related insights responsibly.

## 📌 Note

This dashboard does **not** access any private accounts or databases. All insights are generated from a user-provided list of applications, with estimates clearly labeled where appropriate.
