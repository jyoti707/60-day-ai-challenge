Day 20 – AI Face Puzzle Game 🎮📷

Overview

Built a fully responsive AI Face Puzzle Game using HTML, CSS, and JavaScript. The game accesses the user's webcam, captures a selfie, converts it into puzzle pieces, scrambles them, and lets players solve the puzzle using drag-and-drop or touch controls.

Features

- 📷 Live webcam access using "getUserMedia()"
- 🤳 Capture your own face as the puzzle image
- 🧩 Difficulty levels: 3×3, 4×4, and 5×5
- 🔀 Solvable shuffled puzzle generation
- 🖱️ Mouse drag-and-drop support
- 📱 Touch gesture support for mobile devices
- ⏱️ Live timer with milliseconds
- 🎯 Move counter
- ✅ Correct piece indicator
- 🏆 Win detection with results screen
- 💾 LocalStorage leaderboard (Top 5 scores)
- 🔄 Retake photo, Play Again, and New Photo options
- 📱 Fully responsive UI

Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
- MediaDevices "getUserMedia()"
- LocalStorage

What I Learned

- Working with the Camera API
- Capturing images using Canvas
- Image slicing into puzzle pieces
- Drag-and-drop and touch interactions
- Puzzle state management
- Timer and leaderboard implementation
- Responsive game UI development

How to Run

1. Download or clone the repository.
2. Open the HTML file in Chrome, Firefox, or Safari.
3. Allow camera access.
4. Capture a photo.
5. Select a difficulty.
6. Solve the puzzle and try to beat your best time!
