What this tool does

This is a personal library of reusable AI prompt systems, built for how you actually work — not generic prompts. Instead of retyping context every time, you assemble prompts from swappable building blocks, save the combinations that work, and reuse or loop them on demand.

Dashboard — your saved workflows & activity Prompt Builder — assemble a one-off prompt from blocks (role, context, format...) Loop Builder — turn a prompt into a self-correcting, iterating prompt Workflows — your saved, reusable prompt systems, organized by category

Loop Builder

What is a "loop prompt"? A normal prompt asks the AI once and stops. A loop prompt instructs the AI to keep evaluating and improving its own output against your criteria, in repeated passes, until it meets a stop condition — useful for tasks like refactors, test coverage, or doc polish where "good enough" isn't obvious after one pass.
