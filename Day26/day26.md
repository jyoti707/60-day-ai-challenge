# Day 26 – Prior Authorization Workflow Simulator

## 📌 Overview

For Day 26 of the #60DayClaudeChallenge, I built a **Prior Authorization Workflow Simulator** using HTML, CSS, and Vanilla JavaScript. This interactive application simulates the US healthcare prior authorization process through a gamified drag-and-drop workflow.

## 🚀 Features

- Interactive drag-and-drop workflow
- Three workflow lanes:
  - Patient
  - Provider
  - Payer
- Multiple patient scenarios
  - Elective Surgery
  - MRI
  - Specialty Medication
  - Inpatient Admission
- Medical Necessity Evaluation
- Prior Authorization document collection
- Submission to payer
- Review outcomes:
  - Approval
  - Pend
  - Denial
  - Appeal
  - Peer-to-Peer Review
- Educational explanations after every step
- Progress tracker
- Days elapsed counter
- Efficiency score
- Celebration animation on approval
- Workflow summary dashboard
- Restart / New Patient functionality
- Responsive modern UI

## 🛠 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## 🎯 Simulation Result

- **Scenario:** Inpatient Admission – Post-Surgical Observation
- **Final Outcome:** Approved ✅
- **Days Elapsed:** 5
- **Efficiency Score:** 92%
- **Workflow Status:** Successfully Completed

## 📚 Key Learnings

- Understood the complete Prior Authorization workflow used in US healthcare.
- Learned how medical necessity affects approval decisions.
- Explored document collection and payer review processes.
- Understood Approval, Pend, Denial, Appeal, and Peer-to-Peer Review workflows.
- Improved JavaScript skills by working with drag-and-drop interactions and state management.
- Gained experience in designing workflow-based educational simulations.
