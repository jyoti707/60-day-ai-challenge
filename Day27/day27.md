# Day 27 – Prior Authorization Story Simulator

## 🏥 Project
Built an interactive **Prior Authorization Story Simulator** using **HTML, Tailwind CSS CDN, and Vanilla JavaScript**.

The simulator teaches the healthcare Prior Authorization (PA) workflow through an engaging story featuring Rahul (patient) and Priya (healthcare operations specialist).

## ✨ Features
- Interactive story with 8 healthcare workflow scenes
- Append-only chat interface
- Progress bar showing journey completion
- Choice-based dialogue after every scene
- Beginner-friendly explanations of Prior Authorization
- Insurance review, denial, appeal, and approval workflow
- Educational healthcare design system
- Single-file HTML application

## 🛠 Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript

## 📚 What I Learned
One important thing I learned is that **Prior Authorization is not simply paperwork—it is a structured review process used by insurers to verify medical necessity before approving certain treatments. I also learned that missing documentation, especially step therapy history, is one of the most common reasons for denials, but a denial does not necessarily mean the treatment cannot be approved. Proper documentation and timely appeals play a crucial role in improving patient outcomes.**
