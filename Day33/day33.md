📰 Media Integrity Analyzer

Learn to read between the headlines.

An interactive media-literacy experience built for Day 33 of the #60DayClaudeChallenge.

💡 What I Learned

One surprising lesson from this project is that misleading content doesn't necessarily have to be completely false. A headline can use emotionally loaded words or misleading framing to make accurate information feel much more dramatic than it actually is.

🎯 Features
Challenge 1 — Headline Detective
Analyze fictional news headlines
Compare headlines with article content
Identify exaggerated or misleading phrases
Reveal an accuracy score and fair rewrite
Challenge 2 — Emotion Detector
Analyze fictional social media content
Identify words designed to trigger emotions
Discover manipulation techniques
Understand target audiences
Generate a neutral rewrite
Media Integrity Dashboard
Headline Accuracy
Source Reliability
Emotional Manipulation
Audience Targeting
Overall Media Integrity Score
Key takeaways and practical media-literacy habits

🚀 Goal

The goal is not to test whether users already know media-literacy concepts. Instead, the application uses guided discovery so users first observe and make a judgment, then reveal the reasoning behind it.

Pause. Question. Verify. Then share.
