# Marketing Detective 🕵️‍♂️

An interactive detective-style marketing game where players investigate fictional marketing campaigns, analyze evidence, identify the primary marketing mistake, and learn how the campaign could have been improved.

### What I learned

The biggest lesson from the project was that **high reach and engagement don't necessarily mean marketing success**. A campaign can generate strong top-of-funnel numbers while failing because of problems in messaging, UX, conversion flow, operations, or customer experience.

### Key Features

* Randomized fictional marketing cases
* Interactive investigation board
* Draggable evidence cards
* Campaign metrics and budget analysis
* Customer comments and social media clues
* Multiple-choice case solving
* Case Closed animation
* Learning Report with explanation and improvements
* Responsive dark detective-game UI
* Standalone single-file HTML application

### Built With

* HTML
* CSS
* Vanilla JavaScript
* No backend
* No database
* No external assets
