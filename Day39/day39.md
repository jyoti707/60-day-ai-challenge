# 📄 PDF Splitter & Merger

A premium browser-based PDF utility for splitting and merging PDF documents directly on the client side.

## ✨ Features

### PDF Splitter

* Upload and automatically detect PDF page count
* Visual page thumbnails and page selection
* Custom page ranges
* Split every N pages
* Split after specific pages
* Extract selected pages
* Create multiple split ranges in one operation
* Range validation with invalid-input highlighting
* Result structure preview
* Processing progress indicator
* Automatic PDF downloads

### PDF Merger

* Upload multiple PDF files
* Drag-and-drop file upload
* Display page counts and file previews
* Drag-and-drop PDF reordering
* Total files and total page count
* Estimated output size
* Merge and download as a single PDF

### 🎨 UI/UX

* Premium responsive interface
* Light/Dark mode
* Keyboard shortcuts
* Accessible controls
* Smooth micro-interactions
* Loading and progress states
* Toast notifications
* Responsive mobile layout

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* PDF.js
* pdf-lib

## 🔐 Privacy

PDF processing happens directly inside the browser. Files are not uploaded to a backend server.

The application uses PDF.js for document rendering and pdf-lib for PDF manipulation.
