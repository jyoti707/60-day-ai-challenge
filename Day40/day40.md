# 🤖 AI Assistant Builder

A premium browser-based AI Assistant Builder that guides users from an initial idea to a production-ready AI assistant through a structured, one-question-at-a-time interview.

## ✨ Features

### 🧠 Guided Assistant Creation
- One-question-at-a-time MCQ interview
- Domain and niche discovery
- Target audience and outcome definition
- Input type selection
- Output format selection
- Tone and personality selection

### ⚙️ AI Assistant Brain
- Production-quality system prompt generation
- Defined assistant role and scope
- Output format and response constraints
- Edge-case handling
- Missing information handling
- Irrelevant input handling
- Abuse and safety considerations

### 🎨 Premium UI/UX
- Purpose-built assistant interface
- Domain-specific visual design
- Responsive layout
- Smooth animations
- Loading states
- Error handling
- Empty states
- Interactive micro-interactions

### 📚 Documentation
Includes a collapsible **"How this was built"** section explaining:
- System prompt architecture
- UI/UX design decisions
- How the assistant works
- Possible future extensions
- Tools, memory and multi-step workflow ideas

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Claude API
- Fetch API
