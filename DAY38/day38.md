# Typing Speed Studio — Day 38

A premium, single-page typing practice platform built with **HTML, CSS and Vanilla JavaScript** as part of the **#60DayClaudeChallenge**.

## 🚀 Features

* Time Mode — 15s, 30s, 60s and 120s
* Word Count Mode — 25, 50, 100 and 250 words
* Quote Mode
* Custom Text Mode
* Adaptive Mode
* Zen Mode
* Focus Mode
* Live WPM, Raw WPM, CPM and Accuracy
* Mistake and streak tracking
* Real-time progress indicator
* Correct, incorrect, extra and missed character tracking
* WPM and accuracy analytics
* Mistyped-key analysis
* Achievement badges
* Personal Best tracking
* Session history stored locally
* Dark/Light theme
* Sound effects
* Font-size controls
* Pause/Resume and Restart
* Responsive design
* Accessibility-friendly keyboard interactions

## 📊 What impressed me most

The **analytics dashboard** was my favorite feature.

It goes beyond simply displaying WPM and provides a complete breakdown of the typing session, including accuracy, consistency, character performance, commonly mistyped keys, achievements and personalized improvement suggestions.

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* LocalStorage
* Canvas API
* Web Audio API

The entire application is contained in a **single self-contained HTML file**, with no external frameworks or libraries.
