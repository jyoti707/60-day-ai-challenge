# Day 17 – Build an AI Vehicle Cost & Fuel Analysis Dashboard

## 📌 Objective
Built an interactive Vehicle Cost Analysis Dashboard using Claude AI. The dashboard analyzes vehicle operating costs, maintenance, fuel efficiency, CO₂ emissions, and E85 economics from a CSV dataset.

## 🚀 What I Built
- Responsive HTML dashboard
- Glassmorphism UI with dark navy theme
- KPI cards
- Cost per km comparison
- CO₂ emissions comparison
- Maintenance cost analysis
- Fuel comparison cards
- E85 economics analysis
- Break-even calculation
- SVG charts (Bar, Doughnut, Line)
- Animated SVG Gauge
- Responsive design (Mobile + Desktop)

## 📊 Key Analysis
- Compared Cost/km across all fuel types.
- Evaluated Maintenance Cost/km.
- Compared CO₂ emissions.
- Calculated E85 Pump Savings.
- Measured Running Cost Penalty.
- Calculated Break-even Fuel Price.
- Generated E85 Overall Score.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Pure SVG Charts
- Claude AI
