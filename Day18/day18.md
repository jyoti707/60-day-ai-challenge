# Day 18 - Brain Dump Action Planner

## Objective
Created a reusable Claude Custom Skill named **brain-dump-action-planner** that transforms unstructured meeting notes, brainstorming sessions, transcripts, and brain dumps into a structured, interactive HTML dashboard.

## Skill Description
The skill organizes raw notes into a clean dashboard without inventing any information. It extracts summaries, action items, risks, blockers, conflicts, and open questions while preserving the original details.

## Tools Used
- Claude AI
- Claude Custom Skills
- HTML
- GitHub

## Steps Performed
1. Opened Claude and navigated to the Skills section.
2. Created a new Custom Skill named **brain-dump-action-planner**.
3. Added the provided description and instructions.
4. Saved the custom skill.
5. Tested the skill using sample project meeting notes.
6. Generated an interactive HTML dashboard.
7. Reviewed the generated Summary, Key Takeaways, Action Items, Risks, Blockers, and Open Questions.
8. Captured screenshots of the custom skill and dashboard.
9. Uploaded the screenshots, HTML dashboard, and this documentation to GitHub.

## Features
- Interactive HTML dashboard
- Responsive layout
- Summary section
- Key Takeaways
- Action Items table
- Open Questions
- Risks & Blockers
- Conflict tracking
- Status badges
- Collapsible sections
