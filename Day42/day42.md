# Personal Financial Command Center 💰

An interactive, AI-inspired personal finance dashboard designed to help users **understand, manage, and improve their financial health** — not just track expenses.

## 🚀 Features

* 📊 Financial health score
* 💰 Income and expense tracking
* 📋 Monthly budgeting with category envelopes
* 🎯 Savings goal tracking with progress visualization
* 📈 Interactive spending and cash-flow visualizations
* 🔮 What-If savings simulator
* 🤖 Rule-based financial insights and recommendations
* 🌱 Visual savings-growth tracker
* 📝 Monthly financial checklist
* 💡 Financial literacy tips and AI prompts
* 🌙 Dark/Light mode
* 💾 Local Storage for persistent data
* 🖨️ Printable financial reports
* 📱 Responsive design

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API
* Local Storage

No external libraries or frameworks are required.

## 🎯 Project Goal

The goal of this project is to transform financial management from a simple expense-tracking activity into an **interactive financial decision-making experience**.

Users can monitor their financial health, identify spending patterns, set savings goals, simulate future scenarios, and receive actionable insights from their data.

## ⭐ Highlight

The **What-If Simulator** is one of the key features. Users can adjust:

* Monthly income/allowance
* Savings percentage
* Investment/return assumptions
* Time period

and instantly visualize the projected savings outcome.

## 📂 Project Structure

```text
Personal-Financial-Command-Center/
```

## 💻 How to Run

1. Clone this repository.
2. Open `personal-financial-command-center.html` in any modern web browser.
3. Start adding your financial data.
4. Explore the dashboard, goals, insights, and What-If simulator.

No installation or build process is required.
